# API Map

Every endpoint the app actually calls, joined to the screen that calls it.

- **Companion:** [NAVIGATION.md](NAVIGATION.md) — routes and flow, [FEATURES.md](FEATURES.md) —
  screens and their files. This file owns only the network edge: path → method → screen.
**Read it when** changing an endpoint and needing to know which screens break, tracing a
  screen's network surface before editing it, or checking whether an endpoint is still called.
- **Rule:** no feature builds a URL. Paths live in one router enum
  ([NetworkKit.md](../../docs/modules/NetworkKit.md)); a feature names a case, never a string.

> **Generated by** `Scripts/scan-api-map.py`, rendered by `/sync-app-notes API-MAP`.
> The router enum is discovered **from the call sites**, not by its name — a repo can carry a
> legacy router that still compiles and is never called, and naming it in this file would send
> every reader to the wrong enum.

> Empty until an API router and its call sites exist — `/sync-app-notes` populates it.

- **Built from:** the router enum's path property, `callAPI(path:method:)` call sites, and the
  paired screen for each calling ViewModel
- **Last synced:** never

## Reading a row

| Column | What it is | How it is resolved |
|---|---|---|
| **Method** | HTTP verb | read at the **call site** (`method: .get`), not from the enum — the same case is called with different verbs in some codebases |
| **Path** | the literal, with interpolation normalised | `"…/verify/\(otp)"` → `…/verify/{otp}`. A case with several returns emits **one row per variant**, because a conditional path is two endpoints wearing one name |
| **Screen** | the user-visible title | the localized value behind `title = localizeFor("key")` or `setNavigationTitle(…)`, resolved through `Localizable.strings` |
| **Controller / caller** | the type that owns the call | a ViewModel is resolved to **its screen** — same folder first, then name prefix. `+n` means n further call sites |
| **File** | where the call is written | the calling file, not the screen file, so the row lands on the code that would change |
