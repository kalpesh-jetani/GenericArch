# Index

What this **product** has. What the **repo provides** — every skill, pattern, command, module doc and
note — is [`MAP.tsv`](MAP.tsv); grep that, never this. A thing in neither is a thing nobody finds, so
add the row in the same change that adds the thing.

Maintained by targeted edit: `/learn` adds resource and skill rows, `/sync-app-notes` refreshes the
generated inventories. Every row points at a code path where the thing exists, or a doc where it does
not — never a bare path.
